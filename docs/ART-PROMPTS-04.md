# Dreams — Art Prompts 04: terrain, action cinematics, interiors, NPC life

This is the "what the game is missing after the open-world pass" sheet. Every prompt is
self-contained: paste one block into ChatGPT, it makes FOUR separate images. Save each as
the file name shown and drop them in `art/incoming/`. Order matters: batch 1 first (it is
what makes maps look like Sun Haven), then 2, then the rest in any order.

STYLE (already inside every prompt below, you don't need to track it):
16-bit pixel art, top-down 3/4 view, clean 1px dark outlines, warm saturated palette,
Stardew Valley / Sun Haven feel, flat #FF00FF magenta background with NO shading, NO
gradients, NO drop shadows outside the sprite, NO grid lines, generous 8px gaps between
pieces, every piece in a labelled cell. Each image is 1536×1024.
