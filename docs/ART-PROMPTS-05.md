# Dreams — Art Prompts 05: seamless tiles, character creator, equipment, actions, animals at scale

STYLE (inside every prompt): 16-bit pixel art, top-down 3/4 view, clean 1px dark outlines, warm saturated Stardew Valley / Sun Haven palette, flat #FF00FF magenta background with NO shading, NO gradients, NO drop shadows outside the sprite, NO grid lines, NO labels inside the cells, generous gaps. Each image 1536×1024.

RULE FOR TILE SHEETS (new, important): tiles must be placed in an EXACT grid I can slice by maths: every cell is 96×96 px, cells start at x=24, y=24, with a 24 px gap between cells (so cell N in a row is at x = 24 + N×120; row M at y = 24 + M×120). Each tile is drawn filling its 96×96 cell edge to edge with NO border around it. Put the small label text UNDER the row, never inside a cell. 12 cells per row, 8 rows per image.
