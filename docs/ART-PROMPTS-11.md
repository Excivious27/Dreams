# Dreams — Art Prompts 11: new heroes, recruitable gangsters, the deep mine

WHAT THIS COVERS (checked against the game on 16 Nov, after the tier/mine/creator work): the character select offers only Dad, Mom, Pax, Kairi and the two penguins — you asked for more precreated heroes, each with a gangster version so both arcs can use them; the gangster arc has six thug types and no one new to recruit — you asked for many more gangsters joining the crew through the game; the mine now goes down in tiers (Meadow → Woodland → Deep → Crystal → Dark → Heart) but every floor below 10 reuses the lava/ice tiles and the floor keepers reuse region bosses; enemies now lunge, shoot, shield, stomp, summon and inflict statuses, and all of that is drawn with placeholder circles; four status icons (chilled, slowed, weakened, dazed) and the tier pips are borrowed from other icons.

RULES THAT APPLY TO EVERY IMAGE: 1536×1024, 16-bit pixel art, top-down 3/4 view, clean 1px dark outlines, warm saturated Stardew Valley / Sun Haven palette, flat #FF00FF magenta background, no shading outside sprites, NO GRID LINES, NO TEXT OR LABELS anywhere, no watermark, NO LETTERBOXING (fill the whole 1536×1024). Character sheets use the GRID RULE: 64×96 cells at x = 24 + N×88, y = 24 + M×120 (16 columns, 8 rows), feet at the bottom of the cell, the hero 56 px tall. Tile sheets use the TILE RULE: 32×32 tiles at x = 24 + N×40, y = 24 + M×40, exactly 36 columns, and the art inside each tile must continue across its borders. Isolated props: 16 px gaps, base at the bottom.

EVERY BATCH IS 6 IMAGES. Save every image under the exact file name in quotes and upload to `art/incoming/`.

HERO SHEET LAYOUT (used by Batches 1 and 2 — the same rows as Dad's existing sheet): row 0 IDLE down ×2, up ×2, side ×2, WALK down ×4, up ×4, side ×2; row 1 WALK side ×2 more, RUN down ×4, up ×4, side ×4, HURT ×2; row 2 ATTACK down ×4, up ×4, side ×4, FAINT ×2, CELEBRATE ×2; row 3 HOE down/side/up ×3 each, AXE down/side/up ×3 each (18 cells, use 16 + wrap the last 2 into row 4); row 4 the 2 wrapped axe cells, PICKAXE down/side/up ×3 each, WATER down/side/up ×1 each, HOLD overhead ×1, EAT ×1; row 5 FISHING cast side ×3, reel side ×3, SIT ×1, SLEEP ×1, WAVE ×2, SWIM side ×3, swim down ×1, swim up ×1, float ×1; row 6 RIDE horse (walk side ×4, run side ×2, down ×2, up ×2) drawn 96 px tall so the horse fits, then POWER-UP glow ×4; row 7 VIEWS: front, right, back, left (for the creator and the party menu) ×1 each, then the hero's 96×96 DIALOGUE PORTRAIT drawn across two cells, then 8 spare cells of expressions at portrait size (happy, sad, angry, surprised).
