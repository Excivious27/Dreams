One line per system or tool, grouped by area; each line starts with an [area] tag.

Add a line here (in its area) for every new system, tool or convention; core rules stay in CLAUDE.md.

## [core] Core conventions: input, UI polling, pauses, toasts, settings, menus, haptics, display

- [core] Godot 4.5.1, GDScript, portrait 270×480, `canvas_items` / `keep`, nearest filter. Character strips are 2x detail, drawn at 0.5 scale (`CharacterLibrary`).
- [core] Input goes through actions `up/down/left/right/a/b/menu` (`InputSetup`); `TouchControls` presses the same actions.
- [core] Saves go to `user://` (`SaveGame`).
- [core] Touch buttons press input *actions* (no InputEvents), so UI that reacts to A/B/MENU must poll `Input.is_action_just_pressed` in `_process` (see Dialogue, GameMenu), never rely on `_unhandled_input`.
- [core] After a dialogue/menu closes, `Dialogue.input_blocked()` is true for a moment; gameplay A/B checks respect it.
- [core] Settings live in SaveGame globals via `Settings`; save slots via `GameState.save_key()` (never hard-code "run").
- [core] Full-screen UIs (CraftScreen, HackGame, Epilogue) pause the tree and poll actions; register any on-screen Button rect in `Hud.extra_rects` so TouchControls lets taps through.
- [core] Toasts/pauses: a card that owns the top of the screen joins group `toast_hold` (toasts wait, fades paused) or `toast_under` (toasts sit below its first Control); toasts step in beside the pup strip and energy bar. Every pause needs a visible owner (Dialogue, open GameMenu, or `Hud.modal_rect`): `Hud._pause_watch` lets go of an ownerless pause. Menu sweep: `tools/menu_sweep_test.gd -- [gangsters] [-v]`; toast test `tools/toast_layout_test.gd`.
- [core] Pauses: pause through `Hud.pause(tree, "owner")` (named in the orphan-pause warning); a screen closing restores its "was paused" only if `Hud.keep_paused(tree, self)` (or a modal) still needs it. Battle spawner list = `Battle.spawner_kinds()` (battles.json `_helper_kinds` with `arc`/`flag`/`cost`/`does`). Farm tall grass carries `"walk": true` (not blocked; `farm.sway_grass`, `scythe_sweep` hook from GameMap's weed cut). Bots/reach_all add the mega areas (`mega_areas(arc)`; reach_all `MAPS=a,b` env).
- [core] Softlocks: every menu needs a way out as its last option (B picks it; `Dialogue.is_way_out`; story choices with a key only take Leave/Back/Never mind); `Dialogue.audit` logs menus without one (bots report them). Full-screen UIs must close on B. `GameMenu.story_busy` keeps the menu shut during beats. Probe a stuck spot: `tools/stuck_probe.gd -- scene:x:y`. Test: tools/softlock_test.gd.
- [core] Skippable scenes: `Dialogue.begin_skippable(owner)` / `end_skippable()` (farm opening uses it). Skip/MENU drops lines up to the next choice; lines with `"keep": true` still show. Saves: `tools/save_test.gd` (check.sh) covers first run, 3 slots, reopen at early milestones, corrupt file, old save → Round 13 blocks.
- [core] Taps in drawn screens: read gui_input through `TapInput.press_pos(ev)` / `is_release(ev)` (a phone sends a touch AND its emulated mouse copy; reading both fires twice). An `_input` screen must leave touch releases it didn't start unhandled (TouchControls needs them). Test with real touches: `tools/touch_ui_test.gd` (check.sh).
- [core] Desktop / wide view: `DisplayMode` (scripts/display_mode.gd, autoload DisplayModeSvc) widens the logical view on landscape computer windows (`DisplayMode.view`, height 480; phones/portrait stay 270x480) and centres every CanvasLayer in a 270-px column (`DisplayMode.cx`; Controls anchored to the view get re-anchored to the column). Hud draws right-edge pieces shifted by `DisplayMode.extra()`; screen-space taps in a centred layer go through `DisplayMode.ui(pos)`; camera limits via `GameMap.fit_camera`. A layer that must span the whole view: `set_meta("dm_skip", true)` or `follow_viewport_enabled`. Fullscreen F11/Alt+Enter, settings `fullscreen`, `touch_ui`. Test: tools/desktop_layout_test.gd (`DisplayMode.force/test_size`).
- [core] Menus/Options: reading fonts go through `Settings.font(base)` (Text size, +`TEXT_STEP` px a step); `Settings.text_cps()/toast_hold()/reduced_motion()/timing_factor()`; Options rows via `Settings.header/row_button/note/general_rows`; GameMenu cursor (`move_cursor/press_cursor/cursor_control/step_tab`, `back_one()`, sub-pages in `SUB_PARENT`); optional APIs of other scripts are called through `GameMenu._sc(name)` + `_has_static`. Test tools/menu_pad_test.gd.
- [core] Pad/keyboard on Button screens: `ScreenCursor.make(screen, root)` (spatial cursor over visible enabled Buttons, A presses; on_alt=`action`, on_tool=`tool`, on_page=`cycle_tool`, on_move; `set_meta("pc_key", ...)` keeps it across rebuilds); list repeat `ScreenCursor.Rep.pressed(action, dt)` / `ArcadeGame.repeat_pressed`; drawn decks hide via `deck_hidden()` (`ScreenCursor.pad_active()`); left-handed arcade decks `ArcadeGame.mirror_deck`, bowling `DECK_LH`; SlotDrag pad carry `pad_lift/pad_hover/pad_drop/pad_cancel`; map pins `MegaMap.step_sel`. Test tools/screens_pad_test.gd.
- [core] Controllers: pad bindings `InputSetup.PAD_DEFAULTS` (codes < `AXIS_BASE` = JoyButton, else stick/trigger direction), remap `rebind_pad/pads/reset_pad`, button words `InputSetup.prompt(action)` / `PadInput.words(text)` (never hard-code "Tap USE" in new text); `PadInput` (installed by ensure_actions) = `using_pad()/device_kind()`, `nav_pressed(action)` for list repeat, `shape(v)` walk curve, `rumble()`. Button screens opt into pad play with `PadFocus.enter(root)`/`refresh`/`leave` (focus) or join group `pad_cursor` (virtual pointer; `PadCursor.sending` marks its synthetic mouse events). New actions: cycle_back, ability, pup, rally. Test tools/pad_test.gd (`--fixed-fps 60`).
- [core] Haptics: buzz only through `Haptics.buzz(kind)` (scripts/haptics.gd PATTERNS; SaveGame set_haptics/set_haptics_str/set_haptics_ui); Music.sfx names in `Haptics.SFX` buzz automatically (exact names; never add menu confirms); `Haptics.buzz_amount(shake)` for scripted rumbles; Options rows `Haptics.rows(parent)`. Gameplay timers use `PlayClock.now()/ms()` (game time, stops while paused), never Time.get_ticks_msec(). Test tools/haptics_test.gd.
- [core] Deterministic tests: never wait on the wall clock in a test; wait game time (`gt += root.get_process_delta_time()` per frame) and run it in check.sh with `--fixed-fps 60`; call `seed(n)` in `_initialize`; fixed mine layouts via `(load("res://scripts/mine.gd") as Variant).force_seed = n` (0 = clock). Simulate a loaded box with `--frame-delay 30`.
