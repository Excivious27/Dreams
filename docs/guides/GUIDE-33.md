## How to use the new things (plain words)

**A controller.** Pair any Bluetooth controller (Xbox, PlayStation, Switch) with your phone or computer and press a button: the touch buttons hide and the controller takes over. Tap the screen any time to bring the touch buttons back. Stick or D-pad walks (push all the way to run), A uses, B goes back, X picks the tool, Y checks, Start opens the menu, LB/RB change tools, LT dodges, RT is your partner's power. In the menu, LB/RB switch tabs, the D-pad moves a gold frame, A presses, B steps back. Change any button in Options > Controller buttons.

**The new Options rows.** Options is now in three groups: Sound, Display and controls, This farm. New rows: Text size (normal, large, larger), Text speed (up to instant), Messages stay up (short to longest), Motion and flashes (full or reduced), Timing help (wider fishing window), Vibration (on/off and strength) and Vibrate on button taps.

**Save codes and files.** To keep a copy of a farm: Options > This farm > Back up this farm. It copies a code you can paste into Notes, or saves a file. On the title screen, Save slots lets you copy a code or save a file per slot, load one back, or back up all farms at once. Before a load replaces a farm, the game asks first and keeps the old one as the Restore farm. If a code is broken or from a newer version, it says so and changes nothing. On an iPhone, browsers can clear saved games after a while: back up now and then.

**Vibration.** On Android and with a controller, the game buzzes for fish bites, hits, tree falls, harvests, level ups and big wins. Turn it down or off in Options > Vibration.
