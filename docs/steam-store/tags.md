## Rejected and why

- Crime / Mafia: pulls a mature-crime audience and clashes with the all-ages cozy pitch (revisit after the name decision).
- Open World: regions are separate maps.
- Sandbox, Anime: not what the game is.
- LGBTQ+: romance has no gender checks; tag only if Tom wants that positioning.
- Gambling: the casino is a side venue; never tag.
