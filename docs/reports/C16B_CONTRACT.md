## 2. The long way (P3 builds; P5 supplies content)
- Data: each campaign entry in gen_battles.py (P5) gets `long_way: {kind: "quest"|"toll"|"travel"|"story", id, cost: {money, items}, steps: [...], text, text_gang, unlock_after: "loss"|"skip"|"always"}` both arcs, all ages. Default if missing: a toll + short favour quest generated by P3's code from the campaign's region.
- API (P3, scripts/campaign.gd): `Campaign.long_way(cid) -> Dictionary`, `Campaign.can_take_long_way(cid) -> bool`, `Campaign.take_long_way(cid)` (starts the quest/pays the toll/opens the travel link), `Campaign.long_way_done(cid)` sets st.open[region] and story flags exactly as a win does for access/story, but NOT the win rewards/stars. `Campaign.region_open()` and story gates (STORY_REGION) accept long_way_done. Retry: `Campaign.retry(cid, easier := false)` (easier = one Difficulty step down for that battle only).
- The campaign board (P4) shows "Take the long way" via these calls; after a loss, the loss card (P1 battle.gd or P3) offers Retry / Retry easier / Take the long way / Leave.

## 3. Reward ladder (P4 builds)
- `BattleRewards.on_win(cid, mission_id, stars: int, stats: Dictionary)` grants per-mission stars (1-3: win / win with all allies standing / win under par time), tiered chests (bronze/silver/gold by tier+stars), unique gear/cosmetics/decor/titles (DecorSources.grant for decor), ally upgrades (partner rank xp, crew level xp), recruit unlocks, region perks/shortcuts (TravelNet.unlock for shortcuts), museum trophies, achievements, mastery track per arc. P3/P1 call it on win; `BattleRewards.preview(cid) -> Array` for the board.
- Numbers balanced against C16a economy (battle value per minute ~ fishing/farming at the same stage, not above 1.3x); first-clear bonuses; nothing story-essential.
