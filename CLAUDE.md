# Dreams: notes for Claude

- Project brief: `reference/BRIEF.md` (Tom works only from his phone; short replies ending with play link, what changed, what to test; one question max, last).
- Godot 4.5.1, GDScript, portrait 270×480, `canvas_items` / `keep`, nearest filter. Character strips are 2x detail, drawn at 0.5 scale (`CharacterLibrary`).
- Input goes through actions `up/down/left/right/a/b/menu` (`InputSetup`); `TouchControls` presses the same actions.
- Saves go to `user://` (`SaveGame`).
- Before every push: `bash tools/check.sh` (needs `godot` on PATH or `GODOT=...`). Never push if it fails. CI runs it too.
- `tools/playtest.gd` is a scripted playthrough with asserts and screenshots: `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 540x960 -s res://tools/playtest.gd -- /tmp/shots`. Run it after gameplay changes and look at the PNGs. Delete `~/.local/share/godot/app_userdata/Dreams/save.json` first.
- Touch buttons press input *actions* (no InputEvents), so UI that reacts to A/B/MENU must poll `Input.is_action_just_pressed` in `_process` (see Dialogue, GameMenu), never rely on `_unhandled_input`.
- After a dialogue/menu closes, `Dialogue.input_blocked()` is true for a moment; gameplay A/B checks respect it.
- Art pipeline: Tom uploads ChatGPT sheets to `art/incoming/`; `python3 tools/slice_art.py` keys out magenta, slices, scales to 2x and writes `art/gen/` + `manifest.json`. `Art` (scripts/art.gd) loads from there; `GameMap.prop()` places y-sorted sprites; `Art.draw_tile()` draws 32px tiles into 16px cells. Maps use LINEAR filtering because the art is 2x detail.
- `tools/slice_art2.py` handles batch-2 sheets (tool anims, portraits, villagers, enemies, interiors, seasons...). Both slicers merge into one `manifest.json`; run slice_art.py then slice_art2.py after `rm -rf art/gen`. The keyer treats dark purples as foreground (outlines) and tiles use `cover=True`.
- Characters only in art/gen are listed in `CharacterLibrary.GEN_ONLY` with their strips; missing anims get aliases so every character can idle/walk.
- Player tool anims: `player.play_tool("hoe"|"water"|"axe"|"pickaxe"|"cast"|"reel"|"hold"|"eat")`. `GameMap.fx(name, pos)` plays a one-shot effect from art/gen/fx.
- World: `WorldGen` (scripts/world_gen.gd) densifies maps (ground detail, tree borders/clumps, scatter props, critters, parallax Backdrop). Maps declare exits with `add_exit(rect, scene, spawn, facing, label)`; `GameMap.check_exits()` and `draw_exits()` handle them. Shared interactions for tree/rock/log/stump/bush/forage live in `GameMap.interact_common`.
- Area graph: farm ↔ town ↔ beach/mountain; farm ↔ forest ↔ lake ↔ farm; farm ↔ meadow ↔ crystal_meadow (penguins) / outskirts (gangsters, same scene); meadow → mine; mountain pad → moon.
- Audio placeholders: `python3 tools/make_audio.py` regenerates `audio/music/*.ogg` and `audio/sfx/*.wav`.
- Never delete Tom's uploads (`reference/`, `art/incoming/`). Original characters and art only.
- After slicing art: `python3 tools/art_audit.py --fix` then `godot --headless --path . --import`.
- Keep `docs/STATUS.md` current.
- Workshop: stations, their recipe books and goods are generated by `python3 tools/gen_stations.py` (edit that, not the JSON). `Crafting` runs every station; `Racket` is the gangster arc's heat/bills/laundromat/training; `Sanctuary` is the penguin arc's pool/burrow/shrine. Gangster arc is all-ages: guns are fine (ranged weapons that use `rounds`), but no blood or graphic violence, and no drugs or anything mature.
- Cyber (gangster arc): Hacking Terminal, Chrome Clinic, Robotics Bench are ordinary generated stations; their consumables (scrub, emp, bot, drone) are handled in `GameMap.use_consumable`, bots in `scripts/bot.gd`.
- Gifts: `python3 tools/gen_gifts.py` writes `data/gifts.json` and the `marked_*` enemies / `mk_*` companions (edit that, not the JSON). `Gift` (scripts/gift.gd) drives any enemy with a `gift`; `Marked` handles spawn, yield and recruit. The Marked never die and the arc stays all-ages. `docs/ART-PROMPTS-15.md` is edited by hand now (its generator is frozen).
- Design round generators (edit these, not the JSON): `tools/gen_battles.py` (bf_* regions/scenes, battles.json; `Battle`, `HelperUnit`), `tools/gen_colonies.py` (colony_* regions, colonies.json, cboss enemies, colony items, c_* gifts; `Colony`), `tools/gen_projects.py` (projects.json; `Project`). Run gen_gifts.py after gen_colonies.py (it keeps c_ gifts). `tools/tile_clean.py` writes data/tile_clean.json.
- `tools/slice_art3.py` handles Prompts 16 terrain/kits (seamless ground & water, cliffs, stairs, edges, beach/marsh kits, cave kits, battle structures and helpers); run it after slice_art2.py. `GameMap.seam_cell()` draws seamless textures per cell (8-cell period).
- Art post-steps after slicing: `tools/tile_seams.py`, `tools/tile_clean.py`, `tools/key_water.py`, `tools/set_import_lossy.py`.
- Screenshots of any spot: `tools/area_shot.gd` (scene:x:y args, ARC=gangsters env). `tools/reach_all.gd` walks every map.
- Heart perks and birthdays: `python3 tools/gen_heart_perks.py` (writes data/heart_perks.json and the perk texts/birthdays in data/npcs.json); `Perks` runs them. Endings slideshow: `python3 tools/gen_epilogue.py` → data/epilogue.json; `Epilogue`. Gangster side ops (turf, heists, loyalty favours): `Ops`.
- Settings live in SaveGame globals via `Settings`; save slots via `GameState.save_key()` (never hard-code "run").
- Full-screen UIs (CraftScreen, HackGame, Epilogue) pause the tree and poll actions; register any on-screen Button rect in `Hud.extra_rects` so TouchControls lets taps through.
- Skill trees: edit `tools/gen_skill_trees.py` (base nodes in data/skills_base.json), never data/skills.json. Arc-only skills carry "arc"; use `GameState.skill_in_arc`. New effect keys must be read via `GameState.bonus(skill, key)` somewhere, or they do nothing.
- Missing art list: `python3 tools/missing_art.py` (docs/MISSING-ART.md). Art Prompts 17 is generated by `tools/gen_prompts17.py`.
- Day/night: `GameState.sunset()/sunrise()/darkness()/is_night()` follow the season; `GameMap.sky_tint()` and `NightGlow` (lamps registered by name in `prop()`) use them. Never hard-code evening hours.
- Audio: `Ambience` (scripts/ambience.gd) picks looping beds and spot sounds from time/season/weather/place; placeholders from `python3 tools/make_ambience.py` (audio/amb, new sfx); extra area songs from `python3 tools/make_music_extra.py` (writes only missing tracks). `GameMap.area_track()` picks the song (night, festival, winter farm). `Music.sfx(name, fallback)`; footsteps via `Music.step()`. Real recordings: list file names in audio/amb/REAL.txt or audio/sfx/REAL.txt.
- Enemies: home-tier HP scaling (`Enemy.NATIVE_HP/BOSS_HP`, `hp_scale`); ally/spell hits pass `ally=true` to `Enemy.hit`. Size checks use `base_hp`. Regions get a tier from `Region.AREA_TIER`.
- `Secrets` (scripts/secrets.gd): per-region hidden chest, buried caches (hoe), journal pages; placed beside paths after the map is built.
- Collisions: structures write `GameMap.hard` (blocks even swimmers); bog water isn't wadeable. Tall sprites fade when the player is behind them (`_canopies`).
- Farm soil/crops draw on their own `_soil` layer: field actions call `_soil.queue_redraw()`.
- `tools/fix_overlays.py` after slicing (weather strip border bars). `slice_world.py` `load_hue` keeps enclosed purples (hero fur/capes).
- Art Prompts 18: `docs/src/ART-PROMPTS-18-raw.md` → `python3 tools/build_prompt_files.py` builds 16/17/18 (≤6 images per prompt). Guide 11 is docs/guides/GUIDE-11.md.
